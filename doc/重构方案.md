# 02 · 重构方案（Go + Vue3 + SQLite/PostgreSQL）

## 1. 目标与原则
- **后端**：PHP/Yii2 → Go；**前端**：Vue2 → Vue3；**数据库**：MySQL → **同时支持 SQLite 与 PostgreSQL**。
- **原则**
  1. **接口向后兼容优先**：新后端先复刻现有 `/<controller>/<action>` 与 `{code,msg,data}` 响应，使前后端可**各自独立灰度**、任意组合上线。
  2. **分层重构**：Yii2 的 ActiveRecord + scenario 模式 → Go 的 **Handler / Service / Repository / Model(DTO)** 清晰分层。
  3. **一套代码两种数据库**：靠 GORM 屏蔽 SQLite/PG 方言差异；迁移脚本双份维护。
  4. 顺带清理现状技术债：硬编码盐、schema 漂移、`is_deleted` 类型不一、时间字段混用。

## 2. 目标技术栈
### 2.1 后端（Go 1.22+）
| 关注点 | 选型 | 理由 |
| --- | --- | --- |
| HTTP 路由 | **Gin** | 轻量、易做 `<controller>/<action>` 兼容路由与中间件 |
| ORM | **GORM** | 一等公民支持 SQLite + Postgres 双驱动，AutoMigrate 便利 |
| DB 驱动 | `glebarez/sqlite`(纯 Go，免 cgo) + `gorm.io/driver/postgres` | 避免 CGO 交叉编译问题 |
| 校验 | `go-playground/validator` | 复刻 scenario 的分场景校验 |
| 鉴权 | **JWT**(`golang-jwt/jwt`) + Redis/DB 黑名单（可选） | 替换 DB 明文 token，无状态、更安全 |
| 密码 | `golang.org/x/crypto/bcrypt` 或 argon2 | 替换 md5+硬编码盐 |
| 配置 | `spf13/viper`（env + yaml） | DB 方言、DSN、JWT secret 外置 |
| 迁移 | `golang-migrate/migrate`（推荐）或 GORM AutoMigrate | 生产用 SQL 迁移，本地用 AutoMigrate |
| 日志 | `log/slog` | 标准库结构化日志 |
| 数据字典 introspect | `go-sql-driver/mysql` 连外部库查 `information_schema` | 复刻 DataBaseController 能力 |

> 说明：`database`（数据字典）功能连接的是**外部 MySQL**，与本库选型无关，Go 侧用 MySQL driver 直连并读取 `information_schema` 即可。

| 现状（Vue2） | 目标（Vue3） |
| --- | --- |
| Vue CLI 4 + webpack | **Vite** |
| Vue 2.6 SFC | **Vue 3.4 + `<script setup>`**（可选 TS） |
| Vue Router 3 | **Vue Router 4** |
| Vuex 3 | **Pinia** |
| Element UI 2 | **Element Plus** |
| axios + vue-axios | **axios**（封装实例，直接 import） |
| mavon-editor | **md-editor-v3** 或 **@kangc/v-md-editor**（Vue3 版） |
| vue2-clipboard | **vue-clipboard-plus** 或自封装 `navigator.clipboard` |
| node-sass | **sass (dart-sass)** |
