### 语言来源优先级
```
用户表 lang（登录/刷新时经 /api/user/me 同步） > localStorage(apidoc.lang) > 浏览器语言 > zh-CN 兜底
```
- 切换语言：`setLocale()` 立即生效 → 写 `localStorage` + `<html lang>` → 已登录则回写用户表（失败只提示，不回滚本地）。
- `lang` 为空串表示"未选择"，此时**不覆盖**本地/浏览器判定结果。

## 3. key 命名与书写规范

- 命名：`模块.语义`（如 `nav.apis`、`user.languageChanged`、`property.var.deleteConfirm`），模块名与页面/领域对应。
- 插值用 `{name}` / `{n}`：`t('common.total', { n: total })`。
- 通用词进 `common.*`（保存/取消/删除/已保存/保存失败…），避免在各页面重复定义。
- 组件内：`const { t } = useI18n()`；`App.vue` 用 `useI18n({ useScope: 'global' })` 读 `locale`。
- **新增界面文案一律不再硬编码中文**；中文只保留在代码注释里（项目注释沿用中文）。
- 每次改语言包后跑 `npm run i18n:check`（或 `bash scripts/check.sh` 之外单独跑）。

## 5. 验收方式

1. `npm run i18n:check`：两包 key 一致、无缺失 key（退出码 0）。
2. `npx vue-tsc --noEmit` + `npx eslint src/` + `npm run build`。
3. 无头浏览器（`agent-browser`）：
   - 清空 `localStorage` 且浏览器为 en-US → 首次进入是英文（浏览器判定）；
   - 用户菜单 → 语言 → 简体中文 → 界面即时切中文，`localStorage.apidoc.lang='zh-CN'`、`<html lang>` 同步、**后端 `user_info.lang` 落库**；
   - 刷新保持；**清空 localStorage 再刷新（模拟换设备）仍按用户表语言显示**；
   - naive-ui 内置文案跟随（分页每页条数 `20 / page` ↔ `20 / 页`、输入框 `Please Input` ↔ `请输入`）；
   - 控制台无 `[intlify] Not found ... key` 告警（有告警说明漏了 key）。
