# 当前功能清单

> 依据 `backend/controllers/*` 的实际接口与 `front/src/view`、`front/src/components` 的实际模块整理。
> 路由规则：`/<controller>/<action>`；统一响应：`{ code, msg, data }`；鉴权：query/body 携带 `token`，项目上下文携带 `projectId`。

## 一、按业务模块划分

### 1. 用户与登录
- **前端页面**：`view/user/login`、`view/user/register`、`view/user/myCenter`（个人中心）、`view/user/userManager`（用户管理）
- **后端接口**（`UserController` / `SiteController`）：
  - `site/login`、`site/logout`、`site/index`
  - `user/login` 登录
  - `user/reg` 注册
  - `user/create` 新建用户
  - `user/list` 用户列表 / 查询
  - `user/update` 更新用户资料
  - `user/update-pwd` 修改密码
  - `user/init-pwd` 重置密码
  - `user/check-repeat` 用户名/邮箱/昵称查重
  - `user/get-user-info` 获取当前登录用户信息
- **能力**：注册、登录/登出、token 会话（1h 过期自动续期）、角色区分（普通/管理员/超管）、个人中心资料与头像、用户管理（管理员）。

### 2. 项目与成员权限
- **前端页面**：`view/project/projectList`（项目列表）、`view/project/members`（成员管理）
- **后端接口**（`ProjectController`）：
  - `project/create`、`project/update`、`project/list`、`project/detail`、`project/delete`
  - `project/project-user` 项目成员列表
  - `project/add-user` 添加成员
  - `project/set-leader` 设置负责人
  - `project/quit-project` 退出项目
  - `project/set-permission` 设置成员权限
  - `project/check-operation-permission` 校验操作权限
  - `project/get-project-operation-permission` 获取项目操作权限
- **能力**：项目 CRUD、成员加入/退出、负责人指定、按项目授予 create/update/delete/query 权限并做操作级校验。

### 3. 分组树
- **前端组件**：`components/project/group.vue`
- **后端接口**（`GroupController`）：`group/create`、`group/update`、`group/list`、`group/del`
- **能力**：多级分组（父子 `p_id`）、优先级排序（`priority`）、按类型区分（api / project / doc）。

### 4. 接口文档（API）
- **前端页面/组件**：`view/project/apiPage` → `apiList` / `apiCreate` / `apiEdit` / `apiDetail`；详情单元 `components/api/units/`（`apiInfo`、`requestDataParams`、`returnDataParams`、`detailDescription`）
- **后端接口**（`ApiController`）：`api/create`、`api/update`、`api/list`、`api/detail`、`api/del`、`api/restore`
- **能力**：接口增删改查、软删除与恢复；维护协议、HTTP 方法、URL、请求头、请求参数、返回类型、返回参数、响应样例；支持按分组、关键字检索、分页；创建时按字段映射自动回填返回参数字段。

### 5. 项目文档（Markdown）
- **前端页面/组件**：`view/project/docPage` → `docList` / `docCreate` / `docEdit` / `docDetail`；`components/doc/units/docInfo`
- **后端接口**（`DocController`）：`doc/create`、`doc/update`、`doc/list`、`doc/detail`、`doc/delete`、`doc/restore`
- **能力**：Markdown 文档编写（mavon-editor）、增删改查、软删除恢复、浏览数/点赞数、置顶与优先级、按分组归类。

### 6. Bug 管理
- **前端页面/组件**：`view/project/bug`、`components/bug/userSearchSelect`
- **后端接口**（`BugController`）：`bug/create`、`bug/update`、`bug/assign`、`bug/list`、`bug/assign-list`、`bug/detail`、`bug/delete`
- **能力**：Bug 提交/编辑/删除、状态（待解决/已解决/不处理）、等级、指派处理人（可搜索选人）、指派流转记录与列表。

### 7. 字段映射
- **前端页面**：`view/project/fieldMapping`
- **后端接口**（`FieldMappingController`）：`field-mapping/create`、`field-mapping/update`、`field-mapping/list`、`field-mapping/delete`
- **能力**：维护项目级「字段名 → 类型/描述」字典；接口文档创建时自动匹配回填返回参数的类型与说明。

### 8. 数据字典（外部库元数据）
- **前端页面**：`view/project/dataDict`
- **后端接口**（`DataBaseController`）：`data-base/create`、`data-base/update`、`data-base/list`、`data-base/delete`、`data-base/tables`、`data-base/schemas`、`data-base/schemas-export`
- **能力**：登记外部数据库连接，读取其表清单与字段结构（schema），支持结构导出。

### 9. 操作日志
- **前端组件**：`components/project/operationLog.vue`
- **后端接口**（`OperationLogController`）：`operation-log/list`
- **能力**：记录项目/分组/接口/文档/用户等对象的操作轨迹，按对象分页查询。

### 10. 消息与通知
- **后端接口**（`MessageController`）：`message/send`
- **模型**：`Notification`（站内通知）
- **能力**：验证码/消息发送（手机/邮箱类型），系统站内通知与已读状态。

### 11. 公共属性
- **前端 Mixin**：`mixins/getCommonProperty.js`
- **后端接口**（`PropertyController`）：`property/list`
- **能力**：维护通用标签/属性字典（`tag`/`tag_name`/`description`），供前端下拉等复用。

### 12. 文件上传
- **后端接口**（`FileController`）：`file/upload-img`
- **能力**：图片上传（用于文档/编辑器等）。

## 二、前端整体结构
- **布局**：`view/home.vue`（外层）→ `view/manage.vue`（管理台）→ `view/project/project.vue`（项目详情，含顶部导航）
- **公共组件**：`components/common/topBar.vue`（顶栏：项目名、返回首页、用户下拉「退出登录 / 个人中心」）
- **状态**：`store/main.js`（Vuex：用户信息、当前项目、项目操作权限）
- **请求封装**：`axios.js`（自动注入 `token` 与 `projectId`；`code=34` 触发跳登录）
- **路由守卫**：`router.js`（`requiresAuth` 页面登录后拉取项目操作权限）
- **导航模块**（项目详情内）：接口（apiPage）、文档（projectDoc）、Bug、成员、字段映射、数据字典。
